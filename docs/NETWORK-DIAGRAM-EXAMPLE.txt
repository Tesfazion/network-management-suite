## How Monitoring Works

STEP 1: Normal Operation (Every 60 seconds)
═══════════════════════════════════════════

[Admin Desktop]
192.168.10.100
(Monitoring System)
        |
        ├─ ping → 192.168.10.1 (Core Switch) ──→ ✅ UP (2ms)
        ├─ ping → 192.168.10.11 (Floor1 Switch) → ✅ UP (3ms)
        ├─ ping → 192.168.10.12 (Floor2 Switch) → ✅ UP (4ms)
        ├─ ping → 192.168.20.10 (File Server) ──→ ✅ UP (8ms)

## Cross-VLAN Monitoring Explained

HOW ADMIN DESKTOP MONITORS ALL VLANs
═════════════════════════════════════

[Admin Desktop]                [Core Switch]           [Target Device]
192.168.10.100                 192.168.10.1            (Any VLAN)
VLAN 10 (Management)           Routes between VLANs
        |                              |                      |
        |─── ping 192.168.20.10 ──→   |─── routes to ───→   [File Server]
        |                              |   VLAN 20            192.168.20.10
        |                              |                      VLAN 20
        |                              |                          |
        |    ←─── reply packet ────────|←─── reply from ─────────┘
        |
        └─── Records: UP ✅


Example Paths:

1. Same VLAN (Management):
   Admin Desktop → Core Switch → Floor1 Switch
   (192.168.10.100 → 192.168.10.1 → 192.168.10.11)
   Direct path ✅

2. Different VLAN (Servers):
   Admin Desktop → Core Switch → VLAN routing → File Server
   (192.168.10.100 → 192.168.10.1 → routes → 192.168.20.10)
   Routed path ✅

3. Different VLAN (Staff):
   Admin Desktop → Core Switch → Floor1 Switch → Staff PC
   (192.168.10.100 → 192.168.10.1 → 192.168.10.11 → 192.168.30.101)
   Multi-hop routed path ✅

## Cascading Failure Detection

SCENARIO: Core Switch Fails (Critical)
═══════════════════════════════════════

[Core Switch] ❌ FAILS
192.168.10.1
        |
        └─── Everything downstream unreachable
                    |
        ┌───────────┼───────────┐
        |           |           |
        ↓           ↓           ↓
   Floor1-Sw   Floor2-Sw   Server-Sw
   ❌ DOWN     ❌ DOWN     ❌ DOWN

System shows:
├─ Core-Switch: 🔴 DOWN (PRIMARY FAILURE)
├─ Floor1-Switch: 🔴 DOWN (cascade)
├─ Floor2-Switch: 🔴 DOWN (cascade)
├─ File Server: 🔴 DOWN (cascade)
└─ All devices: 🔴 DOWN (cascade)

Admin immediately knows:
"Core switch is root cause - fix that first!"


SCENARIO: Only Floor 1 Switch Fails (Isolated)
════════════════════════════════════════════════

[Core Switch] ✅ OPERATIONAL
192.168.10.1
        |
        ├─── [Floor1-Sw] ❌ DOWN
        ├─── [Floor2-Sw] ✅ UP
        └─── [Server-Sw] ✅ UP

System shows:
├─ Core-Switch: ✅ UP
├─ Floor1-Switch: 🔴 DOWN (ISOLATED FAILURE)
├─ Floor2-Switch: ✅ UP
└─ File Server: ✅ UP

Admin knows:
"Problem is isolated to Floor 1"
